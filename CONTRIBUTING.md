# Contributing

1. Open a ticket first, or pick an existing one.
2. Create a branch and make your change.
3. Write commit messages in the Conventional Commits format (see the `commit` skill).
4. Open a pull request and link the ticket with `Closes #n` in its description.

The PR agent checks every pull request and posts the results as a comment. See
[docs/pr-agent.md](docs/pr-agent.md).
